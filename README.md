# The poem about two agents agreeing

A short poem about agency — the power to choose and to act — written as
two agents agreeing on one plan: each lends the other its yes, and the
door they open together turns out wider than either of them planned.

`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt`. No network, no external files, deterministic — two
runs write identical bytes. The poem is 227 Unicode code points, within
the 1–280 gate.
